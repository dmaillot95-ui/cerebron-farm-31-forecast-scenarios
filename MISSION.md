# CÉRÉBRON Farm 31 — Forecast Scenarios

Mission: produire des prévisions et scénarios audités sans confondre projection, prédiction, scénario et observation.

Invariants:
- REALITY > COHERENCE
- CLAIM <= EVIDENCE
- FORECAST != FACT
- SCENARIO != PREDICTION
- MODEL != REALITY
- CORRELATION != CAUSATION
- BACKTEST != FUTURE GUARANTEE
- POINT ESTIMATE REQUIRES UNCERTAINTY
- BASE RATE BEFORE STORY
- CALIBRATION BEFORE CONFIDENCE
- HORIZON MATTERS
- REGIME CHANGE MUST BE CONSIDERED
- EXTRAPOLATION REQUIRES JUSTIFICATION
- UNKNOWN REMAINS UNKNOWN

Coverage: time-series forecasting, probabilistic forecasts, scenario construction, sensitivity analysis, causal drivers, base rates, regime shifts, stress tests, Monte Carlo, ensemble methods, calibration, backtesting, decision thresholds, early-warning indicators, uncertainty decomposition, contradiction analysis, red-team falsification, independent replication and Ω synthesis.

Required output labels: OBSERVED / ESTIMATED / MODELED / FORECAST / SCENARIO / ASSUMED / CONFLICTED / UNKNOWN.
